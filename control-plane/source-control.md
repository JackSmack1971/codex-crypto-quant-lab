# Change control
Before modifying repository: record `git status --porcelain=v1`, `git rev-parse HEAD`, staged/unstaged diff and untracked paths when Git exists. Preserve initial user changes; never stage pre-existing changes by default. One writer per overlapping path; independent research agents do not write. After change: focused tests, required repo checks, `git diff --check`, actual diff review, exact changed-files ledger. Local reports are non-public research artifacts; no automatic add/commit/push/PR/merge/release. Track Git state distinct from Codex thread and report identity. No unsupported claim of CI or deployed correctness.
