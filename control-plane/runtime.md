# Environment contract
Target Windows 11 PowerShell, Python >=3.11. Use a local project venv and the pinned package manifest; do not launch MCP through `npx -y`, an installer, or mutable Git spec. The bundled API logic needs no third-party packages for off-network unit checks; live MCP registration requires `mcp==2.3.0` (SDK v2) installed in the designated venv. Record package hashes, Python version, Codex CLI version, OS, checkout and source age in each run manifest. The python MCP SDK 2.3.0 was listed in upstream releases during this research; actual handshake with user's Codex remains unverified. Recovered historical fetch, indicator, and backtest scripts are now bundled under `src/`, with pytest tests. Install optional `[quant]` or `[test]` extras for pandas/NumPy; no runtime handshake or external provider availability is implied.
