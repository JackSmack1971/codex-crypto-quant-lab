# Approval and authority policy
Research-only means no wallet/signing/orders and no authenticated trading endpoints, even in a YOLO parent. This is a design expectation, not a guarantee supplied by AGENTS. The Python adapter enforces fixed provider routes and GET-only HTTP. Keep trading/routing-capable remote MCPs disabled in global config. Do not auto-enable any MCP with funds-transfer, trade, route execution or broad user-data privileges. Locally generated report writes inside workspace are authorized for this purpose; remote publication, Git pushes, PRs, email, external posts, order submission, onchain transactions and paid API upgrades need distinct explicit user authorization and runtime enforcement. If a local Codex session runs unrestricted, enforce network/credentials using an isolated host or proxy. Test actual permission profile, tool restrictions, and resume/fork behavior.
