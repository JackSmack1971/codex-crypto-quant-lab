# Report schema / rich local deliverables
Required sections: title and as-of UTC; one-paragraph executive thesis; question and decision horizon; evidence quality/freshness dashboard; 3-7 key findings with `[R]` retrieved / `[D]` calculated / `[I]` inferred / `[U]` unavailable tags; instrument/venue alignment; scenarios (base/bull/bear) with assumptions and falsifiers; risk and failure conditions; method/fallback disclosure; linked bibliography/source ledger and per-number UTC provenance; data gaps; explicit `NO_TRADE`/`INSUFFICIENT_EVIDENCE` where applicable. Create a locally saved readable Markdown report, and optionally self-contained HTML with accessible responsive tables and **only data-derived charts** (no invented series); when data is absent, show an unavailable panel instead of a misleading chart. Supply companion JSON manifest and reference input/result hashes. Report is analytical research, not order instructions. Do not represent spot depth as full-order-book or cross-venue observations as same-source measurements.

## Research-lab optional annex
When hypothesis competition or historical assessment is performed, report hypothesis IDs, supporting/contradicting signal IDs, shared observation IDs, required-but-missing metrics, explicit falsifiers, method versions, time eligibility, and a ledger run ID/path when recorded. Scores are uncalibrated indices unless independently validated. A local hash-linked record is not proof of input accuracy or externally anchored audit integrity. Never fabricate quantitative predictions or promote a backtest to statistically validated edge.


## Historical strategy annex (v2.3)
When the research laboratory runs, include snapshot ID, model and strategy specifications, run input digest, all NO_DATA periods, hypothetical proxy costs, next-bar timing, rolling walk-forward and CPCV fold identities, and separate CSCV/PBO diagnostics if applicable. Cite the exact selected candidate set and sample size. CPCV fold averages are not a strategy equity curve; CSCV/PBO estimates are exploratory and not calibrated predictive probabilities. The SQLite ledger tip receipt must be retained separately to evidence historical chain continuity against truncation. Use `research_lab.workflows.execute_research_run` for deterministic calculation; do not invent unavailable historical data.
