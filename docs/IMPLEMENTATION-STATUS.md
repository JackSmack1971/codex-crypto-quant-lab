# Coverage and non-claims

## Implemented reference adapters
Fifteen Python MCP-exposed read-only tools plus `quant_capabilities`: Binance spot book/ticker/trades/closed candles; Binance USDM mark/funding, OI and bounded funding history; DefiLlama protocol TVL and chain TVL history; DEX Screener exact pair/token-pair list; mempool.space fee recommendations, mempool, tip, period-averaged hashrate. Fixed GET route registry, no redirects, response byte cap, basic per-provider request spacing, typed Decimal math, unit/source envelopes, schema failures and explicit unavailable outputs. No initial fetch at server startup. Each endpoint's exact behavior and public availability must be verified in target geography.

## Not yet implemented from input design
**Not implemented:** provider response history beyond the opt-in cache, true Binance weight introspection (request weights are static conservative estimates), multi-host comparison, search discovery, DeFi fees/revenue, historic Binance OI and taker ratio, full symmetric-bps-band depth, synthetic continuous orderbook, aligned composite microstructure, advanced report chart generation engine, automated provenance graph, full fixture/schema stress suites, actual Windows MCP handshake. Do not claim v1 spec P0-P3 fully built. This intentionally limited reference is a safe implementation foundation, not production-ready.

## Known risks / checks
1. MemPool public API can change limits and response formats; rate limiting is local and intentionally conservative, not distributed. The single rate-limit authority is `quant_free_mcp.acquisition` (per-provider `min_gap_seconds`, quota window, Retry-After cooldown, circuit breaker); the former `core.RateBucket` was removed as dead code.
2. Source timestamps may be null even when retrieved_at_utc is known. DEX rolling windows and REST books do not prove executable liquidity.
3. Binance futures may be geoblocked; do not bypass region restrictions.
4. DefiLlama protocol slug and returned TVL series mapping must be verified live; fees/revenue are not inferred from TVL.
5. The three legacy Skills now have the recovered `src/market_data.py`, `src/indicators.py`, and `src/backtest.py`, plus their pytest tests. They require optional pandas/NumPy dependencies and are not integrated into the MCP tool registry; live Binance access remains unverified.
6. Every tool is a wrapper around a synchronous network request. P0 adds bounded retries and Retry-After handling (see below); a rate-limited provider is cooled down rather than replayed. State (quota, breaker) is per-process and in memory; the SQLite cache is shared only if `QUANT_FREE_MCP_CACHE_PATH` points at one file. One process recommended.
7. Packaging pins the MCP direct dependency; `constraints-ci.txt` pins direct dependencies for CI. Transitive dependencies are not locked.

## Local report rendering added
`scripts/render_report.py` validates existing observation envelopes and generates Markdown, accessible self-contained HTML evidence tables and a SHA-256 report manifest from an input JSON file. It deliberately does not invent executive research conclusions, scenarios or plotted time series; those require additional researched input/verified authoring. This is a usable report renderer but not a complete autonomous editorial pipeline.

## Recovered legacy quantitative implementation (this package revision)
The user-supplied `tests(1).zip` includes the original three referenced Python implementations and offline pytest fixtures/tests. It also includes `src/edge_forensics.py`, a standalone Base-chain ERC-20 transfer investigative utility. These are bundled unmodified; no new Skill or remote capability is registered. The backtest performs a causal SMA crossover historical simulation with explicit fee/slippage and a lookahead check, but not a validated predictive strategy or a historical resampling scenario laboratory. `pyproject.toml` exposes optional `quant` and `test` extras; dependencies are version-ranged, not locked transitively. Only live market retrieval remains subject to geography, public provider behavior, and availability.

## P0 control-plane hardening (2026-11-12)

- **Acquisition layer** (`quant_free_mcp/acquisition.py`, used by `core.fetch`): injected transport/clock/jitter; SQLite response cache with per-route TTL and stale-if-error windows (opt-in via `QUANT_FREE_MCP_CACHE_PATH`; stale bodies are served only when the caller passes `allow_stale=True` and are labelled `STALE_CACHE` with original retrieval time); static weight-based quota windows; at most `max_attempts` (3) tries with exponential backoff and bounded jitter; `Retry-After` (seconds or HTTP date) honoured only up to a 10 s sleep, otherwise the provider is cooled down with no further HTTP; HTTP 418/429 without a usable `Retry-After` is never retried; CLOSED/OPEN/HALF_OPEN breaker with a single half-open probe; `Acquirer.health()` diagnostics. Fixed routes, HTTPS GET, no redirects, response byte cap and credential-free access are unchanged. `source.cache` and `source.attempts` now appear in envelopes.
- **Fallback qualification** (`research_lab/provider_policy.py`): `MetricContract.coverage` (optional), rejection of `STALE_CACHE` candidates unless allowed, retrieval-after-as-of and availability-before-observation rejection, optional `require_retrieval_time`. A candidate with any differing metric, instrument, venue, unit, interval or method is `INCOMPATIBLE` and never converted.
- **Mission integrity** (`research_lab/mission_integrity.py`, `control-plane/mission-completion.md`): see that document for layers, `research-mission.v2`, and the `VALIDATED` migration.
- **Qualification**: `.github/workflows/ci.yml` (offline: structural/manifest validation, compile/import, dependency check, stdlib suites on Python 3.11 and 3.13, full pytest with pinned direct dependencies on 3.13) and `live-providers.yml` (manual, opt-in; `tests/live`). Offline fault-injection: `tests/test_acquisition.py`; evidence-tampering/invalid-mission: `tests/test_mission_integrity.py`.
- **Fixed defect:** `PACKAGE-MANIFEST.json` was stale for `tests/fixtures/synthetic-mission-bundle/mission.json` at baseline. Regenerate after adding or changing managed files by re-hashing `scripts/verify_control_plane._managed_files(ROOT)` into the `files` map of `PACKAGE-MANIFEST.json`; `python scripts/verify_control_plane.py` reports any mismatch.
- **P0 audit repairs (F01-F10)** (`tests/test_p0_regressions.py`): the circuit breaker now issues settle-once tickets so every HALF_OPEN probe is released on redirects, errors and cancellation; transport I/O and backoff sleeps run outside any lock (per-provider locks guard state only); a Retry-After retry no longer forces the breaker CLOSED; `core.RateBucket` was removed (`acquisition` is the only rate-limit authority); mission verification rejects non-finite Decimals, validates cross-validation folds structurally, classifies archive failures by exception type (`EvidenceMissing`, `ArchiveIntegrityError`, `ArchiveDatabaseError`) instead of message text, reports malformed evidence references without duplicate-tracking them, and closes archives it opened itself (never caller-supplied ones); `qualified_fallback` rejects impossible provenance ordering and invalid or contradictory cache metadata.
- **Fixed defect:** the environment ran on pandas 3.0.5 although `pyproject.toml` declares `pandas>=2.1,<3`; CI now pins pandas 2.3.3 and `scripts/check_dependencies.py` enforces pin/range consistency.

Still not done: live probes were not executed here; request weights are estimates; no cross-process quota/breaker state; no cryptographic authentication or independent reviewer attestation; scientific validity is never asserted by the verifier.
