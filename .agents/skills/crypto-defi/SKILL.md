# DeFi research
Start from canonical protocol slug, chain and contract address; validate token-protocol link from primary docs. TVL != revenue != token-holder cash flow != market cap. Separate chain-aggregate from project TVL and possible bridged/double-counted accounting. On DEXes identify exact pool address, base/quote tokens, pool-specific depth, reported volume, liquidity USD, creation timestamp and source. A source absence means unavailable, not zero; marketing boosts do not prove adoption. Explicitly state if the requested free source omits fees/revenue. Produce source ledger and counterarguments for sustainable value capture.
