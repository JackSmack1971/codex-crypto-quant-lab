# Risk and inference review
Check source quality/freshness, leakage, data snooping, lookahead, small samples, nonstationarity, unrealistically low fees/slippage, depth sampling, spread, token holder concentration, pool slippage, depeg, contract exploit and venue insolvency risks as relevant. Separate realized volatility from predictive edge; include bullish/bearish mechanisms and invalidation criteria. Favor risk-adjusted sensitivity and out-of-sample evaluation when data support it, else label untested. Present most consequential unverified assumptions first. Issue NO_TRADE when decision-critical inputs fail. This is research review, not financial authorization.
